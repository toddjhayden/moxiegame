# 🐦 Moxie's Bug Catcher! 🐛

A fun game where you play as a bird catching bugs!

## How to Play

1. Open `index.html` in your web browser
2. Click "Let's Play!" to start
3. Move your mouse (or finger on mobile) to fly the bird
4. Catch bugs to earn points!

## Scoring

| Bug | Points |
|-----|--------|
| 🦋 Butterfly | 10 |
| 🐛 Caterpillar | 15 |
| 🐞 Ladybug | 20 |
| 🦗 Leaf Cricket | 25 |
| 🐝 Red Wasp (Texas!) | 30 |
| 🐛 Giant Centipede (Texas!) | 40 |
| ✨ Golden Bug | 50 |

## Features

- 60-second timed rounds
- Colorful graphics with a cute bird character
- Different bugs worth different points
- Particle effects when catching bugs
- Works on desktop and mobile!
